Mark It Down

Write it down. Keep it yours.

無料・ローカル完結 Markdown エディタ

自分の言葉に書き直すための、
ローカル Markdown エディタ。

AI執筆なし · アカウント不要 · 自動同期なし

AI出力、Web記事、RSS、空白のノートを取り込む。
必要な部分を、自分の言葉に書き直す。
できあがったら、Export または Git で送り出す。

Philosophy

哲学

AI執筆、カスタムフォルダ、ノートの自動同期は載せなかった。
残したのは、自分で書き直し、残すものを決め、完成したノートを送り出すためのローカルな作業場。

  • AIに書かせる機能も、ノートの自動同期も入れない。

    AIはエディタの横で使う。中には入れない。
    ノートの準備ができたときだけ、自分で Git 同期を実行する。

  • 保存じゃなくて、咀嚼。

    コピペでは自分のものにならない。
    書き直すことで自分の言葉になる。

  • ローカルに保存し、意図して送り出す。

    下書きは自動保存で手元に残ります。
    Export と Git 同期は、ノートの準備ができたときに実行します。

Workflow

Entry → Edit → Move → Exit

ブラウザで動作する切り取りメモ。

  • Entry

    AI出力を貼り付ける。
    ページをクリップする。RSSを保存する。空白から書く。

  • Edit

    自分の言葉で。
    自分のものにする。

  • Move

    終わったものはArchiveへ。
    繰り返す型はTemplateへ。不要なものはTrashへ。

  • Exit

    PDF、DOCX、HTML、EPUB、LaTeX、.md、Git。
    できあがったノートを、次の場所へ送ります。

Use Cases

実際の使い方

  • Xを記事でもスレッドでも取り込むX / Twitterの記事でもスレッドでも、右クリックの取り込みで即Markdownに変換して保存。
  • 複数環境の日次ログノートのタイトルを日付（例 YYYYMMDD）にして、メモは /now の時刻見出しで追記。別の端末で編集しても、Git同期が競合を検出し「両方を結合」で1つにまとめられる。
  • 横で読みながらメモ、タブで集中Webを見ながらSide Panelでメモ。閉じてNew Tabで同じノートを開き、じっくり編集。
  • 思いつくまま書いて並べ替えリストを思いつくまま書いて、Alt+↑ / ↓ で行を並べ替えて整える。
  • 読み上げとハイライトで語学学習教材を貼り付けて再生すると、読み上げ中の文がハイライトされる。Natural音声で聞きたいときは、Microsoft Edgeの読み上げ機能を使うと高品質な音声の選択肢が増える。

FAQ

よくある質問

無料で使えますか？

はい、完全無料です。広告なし、有料プランなし、アカウント登録も不要です。

オフラインで使えますか？

はい、ほぼすべての機能がオフラインで動作します。ノートの作成、編集、検索はすべてオフラインで可能。Git同期のみインターネット接続が必要です。

ブラウザのキャッシュを消すとノートも消えますか？

いいえ、消えません。ノートは拡張機能専用のストレージに保存されており、ブラウザキャッシュとは別です。データは安全です。
